# ixi-O 통화 품질 자동화 테스트 플랫폼

> **LG U+ 익시오(ixi-O) 앱의 통화 품질을 자동으로 검증하는 End-to-End 테스트 솔루션**

---

## 1. 왜 만들었나?

### 기존 문제점

| 기존 방식 | 문제 |
|-----------|------|
| 사람이 직접 통화하며 청음 | 시간 소요, 주관적 판단, 재현 불가 |
| 수작업 녹음 후 비교 | 반복 테스트 어려움, 일관성 부족 |
| 단말별 개별 테스트 | iOS↔Android 교차 검증 누락 |

### 우리 솔루션

```
실제 단말(iPhone ↔ Galaxy)에 자동으로 전화를 걸고,
미리 준비한 음원을 재생한 뒤,
녹음된 통화 음성을 정답지와 비교하여
"어디서 소리가 끊겼는지, 품질은 어떤지"를 자동 판정합니다.
```

## 3. 주요 기능

### 3-1. 자동화된 통화 테스트

| 기능 | 설명 |
|------|------|
| **자동 전화 걸기/받기** | iPhone ↔ Android 간 전화를 자동으로 제어 |
| **음원 자동 재생** | USB 사운드카드를 통해 통화 중 음원 자동 전달 |
| **통화 녹음 수집** | 양쪽 단말의 통화 녹음 파일을 자동으로 수집 |
| **스크린샷 캡처** | 통화 시작/종료 시점 화면 자동 저장 |
| **반복 테스트** | 동일 시나리오를 N회 반복 실행 가능 |

> **5단계 수신 전략**: 화면 잠금, UI 변화 등 다양한 상황에서도 전화를 안정적으로 받을 수 있도록 5가지 수신 방법을 자동 전환합니다.

### 3-2. 테스트 시나리오 (TC)

| TC | 시나리오 | 목적 |
|----|----------|------|
| **TC_01** | 일반 통화 (iPhone↔Android 양방향) | 기본 통화 품질 검증 |
| **TC_02** | 보이스피싱 시나리오 | 피싱 통화 상황에서의 음질 검증 |
| **TC_03** | MOS 음질 측정 전용 | 정밀 음질 점수 산출 |
| **TC_04** | 역방향 피싱 시나리오 | 발신/수신 방향 반대 테스트 |

## 4. 음원 분석 기능 (핵심 특장점)

통화가 끝나면 녹음된 음성을 **정답지(원본 음원)**와 자동 비교하여 품질을 판정합니다.

### 4-1. 음단절(Dropout) 탐지

> **"통화 중 소리가 끊기는 구간"을 자동으로 찾아냅니다.**

```
정답지(원본)  ████████░░░████████████░░████████
녹음(실제통화) ████████░░░████░░░░████░░████████
                              ▲▲▲▲
                         여기가 음단절!
```

#### 분석 방식

**① 스크립트 기반 탐지**
- 원본 음원의 **대사(문장)를 한 줄씩** 분리
- 각 대사가 녹음본에서 제대로 들리는지 **상관계수(Correlation)**로 판정
- 상관계수 0.30 미만 → **음단절로 판정**
- 결과: "몇 번째 대사, 몇 초~몇 초 구간에서 소리가 끊겼다"

**② 에너지 프로파일 비교**
- 20ms 단위로 소리의 세기(에너지)를 측정
- 원본에는 소리가 있는데, 녹음본에서 소리가 없는 구간 탐지

**③ 이상 구간 검출 (Anomaly Detection)**
- **묵음(Digital Zero)**: 원본에 소리가 있는데 녹음이 완전 무음인 경우
- **깨짐(Gain Drop)**: 소리가 급격히 작아지거나 왜곡된 경우
- 최소 50ms 이상 지속된 이상만 필터링하여 오탐 방지

### 4-2. 음질 측정 (MOS 점수)

> **"통화 품질을 1~5점으로 점수화합니다."**

| 등급 | 점수 범위 | 체감 품질 |
|------|-----------|-----------|
| EXCELLENT | 4.5 ~ 5.0 | 원음과 거의 동일 |
| GOOD | 4.0 ~ 4.5 | 양호한 통화 품질 |
| FAIR | 3.5 ~ 4.0 | 보통 수준 |
| AVERAGE | 3.0 ~ 3.5 | 약간 열화 느껴짐 |
| POOR | 2.5 ~ 3.0 | 불량 |
| BAD | 1.0 ~ 2.5 | 통화 곤란 |

#### 측정 방법

| 지표 | 설명 |
|------|------|
| **ViSQOL** | AI 딥러닝 기반 음질 점수 (가장 정밀) |
| **PESQ** | 국제 표준(ITU-T) 음질 측정 알고리즘 |
| **SNR** | 신호 대 잡음비 (dB) — 잡음이 얼마나 섞였는지 |

### 4-3. 파형 정렬 (Waveform Alignment)

> **"녹음 파일과 원본 파일의 시간축을 정확히 맞춥니다."**

통화망을 거치면 원본 대비 약간의 **시간 지연(delay)**이 발생합니다.
이 지연을 자동 보정하지 않으면 모든 분석 결과가 틀어집니다.

```
원본    │▓▓▓▓▓░░░▓▓▓▓▓▓░░░▓▓▓▓│
        │                      │
녹음    │░░░▓▓▓▓▓░░░▓▓▓▓▓▓░░░▓│  ← 0.6초 지연
        │                      │
보정 후  │▓▓▓▓▓░░░▓▓▓▓▓▓░░░▓▓▓▓│  ← 정확히 정렬!
```

- **FFT Cross-Correlation**: 원본과 녹음의 파형을 비교하여 최적 오프셋 자동 계산
- **정밀도**: 샘플 단위(약 0.02ms) 정확도

### 4-4. Gemini AI 청음 분석

> **"AI가 사람처럼 녹음을 직접 듣고 평가합니다."**

- Google Gemini AI에 녹음 파일을 전송
- 대사별 음질, 자연스러움, 끊김 여부를 인간 관점에서 판정
- 신호 처리 결과와 AI 판정을 교차 검증 → **하이브리드 분석**

## 5. 자동 HTML 보고서

테스트가 끝나면 아래 내용을 포함한 **보고서가 자동 생성**됩니다.

```
┌────────────────────────────────────────────┐
│  ixi-O 통화 품질 테스트 보고서              │
│  2026-04-02 09:42:58                       │
├────────────────────────────────────────────┤
│                                            │
│  ■ 테스트 요약                              │
│    iOS MOS: 3.8 (보통)                     │
│    Android MOS: 4.2 (양호)                 │
│                                            │
│  ■ 음단절 탐지 결과                         │
│    ┌──┬───────┬────────┬──────┬──────┐     │
│    │# │ 화자  │ 구간   │길이  │판정  │     │
│    ├──┼───────┼────────┼──────┼──────┤     │
│    │1 │Android│22.5~31s│8.5초 │음단절│     │
│    │2 │iOS    │42~47s  │5.4초 │음단절│     │
│    └──┴───────┴────────┴──────┴──────┘     │
│                                            │
│  ■ 파형 비교 그래프                         │
│    [원본 vs 녹음 파형 이미지]               │
│                                            │
│  ■ 이상 이벤트                              │
│    묵음: 3건 / 깨짐: 2건                    │
│                                            │
└────────────────────────────────────────────┘
```

- **다크 테마** 디자인으로 가독성 확보
- 파형 비교 차트, 스펙트로그램 등 시각 자료 포함
- `reports/daily/` 폴더에 날짜별 자동 저장

## 7. 차별화 포인트

### ① 실기기 기반 End-to-End 테스트
- 에뮬레이터가 아닌 **실제 단말 + 실제 통화망**에서 테스트
- 실 사용 환경과 동일한 조건에서 품질 검증

### ② 다중 분석 엔진
- 단일 방식이 아닌 **4가지 분석 방식**으로 음단절 교차 검증
- AI 청음 + 신호 처리를 결합한 **하이브리드 분석**

### ③ 완전 자동화
- 전화 걸기 → 음원 재생 → 녹음 수집 → 분석 → 보고서까지 **원클릭**
- 야간/주말 무인 반복 테스트 가능

### ④ 정밀한 파형 정렬
- FFT 기반 Cross-Correlation으로 **샘플 단위 정밀 보정**
- 통화 지연에 의한 오탐 방지

### ⑤ 보이스피싱 시나리오 지원
- 실제 피싱 대본 기반 시나리오 테스트
- 피싱 차단 기능이 통화 품질에 미치는 영향 측정
