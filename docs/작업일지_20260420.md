## iOS 무선 연결 안정성 개선 — WDA.ipa 설치 + 회차 간 연결 점검/자동복구

### 배경

4월 17일 10회 반복 테스트 중 7~8회차에서 **iPhone 무선 연결(tunneld IPv6 터널)이 끊어져** ERROR 발생. 수동으로 재연결 후 남은 회차를 진행했으나, 자동화 테스트의 신뢰성이 떨어지는 상태.

### 현재 상태 (As-Is)

| 구성 요소 | Android | iOS |
|---|---|---|
| Watchdog (연결 감시) | `android_watchdog.py` — 30초 주기 체크 + keepalive | **없음** |
| 장애 시 자동 재연결 | 지수 백오프 + ADB kill/restart | **없음** |
| 회차 간 연결 확인 | watchdog이 상시 보장 | **없음** — 3초 sleep 후 바로 다음 회차 |
| WDA 프로세스 감시 | N/A | **없음** — 사망 시 수동 개입 |

**문제 시나리오**:
```
회차 6: PASS
  ─── iPhone tunnel 끊김 ───
회차 7: Appium → WDA /status 타임아웃 → ERROR
회차 8: WDA 여전히 접근 불가 → ERROR (연쇄 실패)
  ─── 수동 재연결 ───
회차 9: PASS
```

### 개선 계획

#### Phase 1: WDA.ipa 사전 설치

| 항목 | 내용 |
|------|------|
| 목적 | WDA 프로세스 안정성 확보 (Xcode 빌드 30분 제약 해소) |
| 방법 | 기존 빌드된 WDA.ipa를 `wda_installer.py`로 설치 |
| 설치 도구 | tidevice → ideviceinstaller → pymobiledevice3 (우선순위) |
| 번들 ID | `com.jjun.1.WebDriverAgentRunner` |
| 효과 | 인증서 유효기간까지 WDA 무제한 생존, `devicectl process launch`로 안정적 재기동 가능 |

#### Phase 2: 회차 간 Preflight Check + 자동 복구

**useTcRunner.ts 반복 루프에 삽입할 로직**:
```
for 회차 in 1..10:
  ❶ invoke("preflight_ios_check")
     ├─ check_iphone_connection (devicectl list devices)
     ├─ 실패 → recovery 파이프라인
     │     ├─ tunneld 재시작 (launchctl kickstart)
     │     ├─ 10초 대기 (tunnel 안정화)
     │     ├─ WDA /status 확인 (8100→8200→27753)
     │     ├─ WDA 미응답 → launch_wda_via_devicectl()
     │     └─ 최대 60초 폴링 (5초 간격 × 12회)
     └─ 복구 성공 → 테스트 진행 / 타임아웃 → ERROR + 사유 기록
  ❷ runSingleTc()
  ❸ sleep(3000)
```

#### 구현 대상 파일

| 파일 | 변경 내용 |
|------|----------|
| `ios_wda_manager.py` | `ensure_ready()` 메서드 신규 — 연결확인 + WDA 상태확인 + 필요 시 복구 파이프라인 |
| `device_cmd.rs` | `preflight_ios_check` Tauri 커맨드 — Python `ensure_ready()` 호출 래퍼 |
| `useTcRunner.ts` | 반복 루프 회차 시작 전 `invoke("preflight_ios_check")` 호출 + 결과에 따른 분기 |

#### 복구 타이밍 분석

| 장애 유형 | 복구 소요 시간 (추정) | 성공 확률 |
|---|---|---|
| tunnel 일시 끊김 (Wi-Fi 전환) | tunneld 자동재시작 5초 + 안정화 10초 = ~15초 | 높음 |
| tunnel 완전 끊김 (iPhone 잠자기) | tunneld 재시작 + tunnel 재수립 = ~20초 | 중간 |
| WDA 프로세스 사망 | devicectl launch + 폴링 = ~35초 | WDA.ipa 있으면 높음 |
| iPhone Wi-Fi 자체 끊김 | 복구 불가 (수동 개입) | 불가 |

#### WDA.ipa 유무에 따른 자동복구 차이

| 상황 | .ipa 없음 | .ipa 설치됨 |
|------|-----------|-----------|
| WDA 재기동 | `devicectl launch` → 서명 만료/Preparing 무한루프 가능 | **안정적 기동** |
| WDA 생존시간 | Xcode 빌드 기준 30분 제약 가능 | **인증서 유효기간까지 무제한** |
| Phase 2 자동복구 효과 | 불안정 | **안정적** |
