# 음단절 검출 기법 비교 분석: 대본 기반 vs 오디오 기반

**작성일:** 2026-04-06  
**대상 파일:** `script_gap_detector.py` (대본 기반) · `audio_anomaly_detector.py` (오디오 기반)  
**통합 실행:** `analyze_hybrid.py`

---

## 1. 개요

이 프로젝트에는 통화 녹음에서 음단절을 검출하는 두 가지 독립적인 기법이 공존합니다.

| 구분 | 대본 기반 | 오디오 기반 |
|------|-----------|-------------|
| 파일 | `script_gap_detector.py` | `audio_anomaly_detector.py` |
| 핵심 함수 | `analyze_by_script()` | `detect_dif_only_events()` |
| 분석 단위 | 대사 문장(발화 구간) | 20ms 프레임 슬라이딩 윈도우 |
| 주요 지표 | 에너지 엔벨로프 cross-correlation | RMS·peak·correlation + context ratio |
| 입력 조건 | 대본(SCRIPT_REFERENCE) 필요 | 대본 불필요, WAV 2개만 있으면 됨 |

## 2. 대본 기반 검출 (`script_gap_detector.py`)

### 2.1 알고리즘 흐름

```
① 대본 파싱        → [(화자, 대사), ...]
② 정답지 VAD 분절  → 묵음 700ms↑ = 새 발화 경계
③ 발화 ↔ 대사 매핑 → 순서 기반 자동 정렬
④ 전역 오프셋 추정 → FFT cross-correlation
⑤ 구간별 에너지 상관 → ±8s 탐색 창으로 슬라이딩
⑥ 음단절 판정      → max_corr < 0.30 → ❌ 음단절
                     max_corr ≥ 0.92 → ✅ 정상 (frame scan 스킵)
⑦ frame-level scan → CORR_GOOD 미만일 때만 실행
                      100~300ms 단위 세밀 묵음 탐지
```

### 2.2 핵심 파라미터

| 파라미터 | 값 | 의미 |
|---|---|---|
| `SILENCE_GAP_MS` | 700ms | 발화 경계 구분 최소 묵음 |
| `CORR_THRESHOLD` | 0.30 | 음단절 판정 최소 상관계수 |
| `CORR_GOOD` | **0.92** | frame scan 스킵 기준 (오탐 방지) |
| `_partial_min_ms` | **100ms** (tail: 300ms) | frame scan 최소 묵음 지속 시간 |
| `SEARCH_SEC` | ±8.0s | 각 구간 탐색 창 |

### 2.3 경쟁력

**① 발화 구간 특정 가능**  
어떤 화자의 몇 번째 대사에서 음단절이 발생했는지 명확히 알 수 있습니다.  
→ 디버깅, 보고서, 사용자 피드백 모두 "철수 3번째 발화에서 음단절"처럼 명확합니다.

**② 화자 간 자연 공백 오탐 없음**  
VAD 분절 + 대본 매핑으로 화자 전환 구간, 대화 포즈, 상대방 발화 구간을 완전히 제외합니다.  
→ 일반 오디오 기반 방식이 오탐하기 쉬운 "화자 교체 시점 묵음"을 원천 차단합니다.

**③ 짧은 음단절 검출**  
에너지 상관 + frame scan 2단계 구조로 **100ms 이상** 묵음도 검출 가능합니다.  
(오디오 기반의 `min_anomaly_ms`=50ms와 유사한 수준)

**④ 대본 구조 활용한 맥락 이해**  
- PAD 구간(정답지 끝 이후)에서 시작하는 묵음 자동 무시  
- 의도적 묵음 처리 구간(지시 사항)과 실제 음단절 구별 가능

## 3. 오디오 기반 검출 (`audio_anomaly_detector.py`)

### 3.1 알고리즘 흐름

```
① WAV 로드 + 리샘플링 (float32)
② Cross-correlation 지연 추정 → DTW 세부 보정 → 정렬
③ 20ms 프레임 / 10ms 홉 → ref_rms, dif_rms, dif_peak, frame_corr 추출
④ context_med 계산 → ±1초 내 현재 ±200ms 제외한 구간 ratio 중앙값
⑤ 묵음 검출 (digital_zero):
     dif_peak < 0.0005 + ref_rms > 0.03 → 최소 50ms
⑥ 깨짐 A 검출 (gain_drop Type A):
     ratio < context_med×0.4 + corr > 0.3 → 최소 50ms
⑦ 깨짐 B 검출 (gain_drop Type B):
     ratio < context_med×0.35 + gap 3프레임 허용 → 최소 120ms
⑧ 3단계 오탐 필터:
     - 직전 200ms dif 비활성 → 자연 전환 구간 제외
     - 묵음 직후 200ms 내 깨짐 → 복구 과도 구간 제외
     - 안정 ratio 구간 재확인
⑨ 결과: [{type, start_s, end_s, duration_ms, gain_db, correlation}, ...]
```

### 3.2 핵심 파라미터

| 파라미터 | 기본값 | 의미 |
|---|---|---|
| `speech_strong_rms` | 0.03 | ref 확실한 음성 판정 |
| `zero_peak_threshold` | 0.0005 | dif 디지털 제로 판정 |
| `gain_drop_ratio` | 0.4 | 깨짐 A: 주변 대비 ratio 임계값 |
| `gain_drop_ratio_strict` | 0.35 | 깨짐 B: 더 엄격한 ratio 임계값 |
| `min_anomaly_ms` | 50ms | 묵음/깨짐 A 최소 지속 시간 |
| `min_anomaly_b_ms` | 120ms | 깨짐 B 최소 지속 시간 |

### 3.3 경쟁력

**① 대본 없이 사용 가능 (범용성)**  
WAV 파일 2개(ref + dif)만 있으면 즉시 분석 가능합니다.  
→ 대본이 없는 임의 통화 녹음, 현장 수집 데이터, A/B 테스트 등에 바로 적용 가능합니다.

**② 묵음뿐만 아니라 "깨짐"까지 검출**  
`gain_drop` 타입은 묵음은 아니지만 볼륨이 급감하거나 신호가 왜곡된 구간을 포착합니다.  
→ 대본 기반 방식으로는 잡기 어려운 "소리는 나지만 품질이 급격히 나빠진" 구간을 커버합니다.

**③ DTW 기반 누적 드리프트 처리**  
여러 번의 음단절로 인해 ref/dif 시간 축이 벌어지는 경우도 DTW 정렬로 자동 보정합니다.  
→ 대본 기반의 전역 오프셋 추정만으로는 불안정해지는 케이스를 견고하게 처리합니다.

**④ ms 단위 정밀 타임스탬프 + 수치 제공**  
각 이상 구간의 `start_s`, `end_s`, `gain_db`, `correlation` 수치가 포함된 구조화 데이터를 반환합니다.  
→ 자동 리포팅, 데이터 수집, 품질 지표 추적에 적합합니다.

## 4. 두 기법의 관계: 경쟁 vs 보완

### 4.1 탐지 범위 비교

```
[ 대본 기반이 잘 잡는 것 ]              [ 오디오 기반이 잘 잡는 것 ]
──────────────────────────              ────────────────────────────
화자 특정 음단절(누가, 몇 번째)         대본 없는 임의 구간 이상
화자 전환 오탐 완전 없음                gain_drop(깨짐, 왜곡) 검출
짧은 묵음(100ms↑) 정밀 검출            다중 음단절 후 드리프트 대응
PAD/묵음 처리 구간 구별                 ms 단위 정밀 좌표 + gain 수치

[ 두 방법 모두가 잡는 것 ]
──────────────────────────────────────
명확한 음단절 (묵음 200ms↑, 화자 발화 중 발생)
```

### 4.2 오류 특성 비교

| 오류 유형 | 대본 기반 | 오디오 기반 |
|---|---|---|
| False Positive (오탐) | 낮음 — 화자 발화 구간만 검사 | 중간 — 자연 전환 구간 오탐 가능 |
| False Negative (미탐) | 중간 — 화자 미매핑 시 누락 가능 | 낮음 — frame 단위 전수 검사 |
| 깨짐(gain_drop) | 검출 어려움 | 검출 가능 |
| 짧은 묵음(50~100ms) | 100ms↑ 검출 | 50ms↑ 검출 |

## 5. 공존 시너지

### 5.1 교차 검증으로 신뢰도 향상

```
대본 기반 검출    오디오 기반 검출    해석
──────────────────────────────────────────────────────
    ✅ 검출          ✅ 검출        → 확실한 음단절 (High confidence)
    ✅ 검출          ❌ 미검출      → 대사 단위 묵음 (짧거나 부분적)
    ❌ 미검출        ✅ 검출        → 깨짐 or 화자 외 구간 이상
    ❌ 미검출        ❌ 미검출      → 정상 통화
```

두 방법이 모두 검출한 경우: 보고서에서 높은 확신도(★★★)로 표시 가능  
한 방법만 검출한 경우: 경계 케이스로 표시하여 수동 확인 유도

### 5.2 역할 분담

| 역할 | 담당 기법 | 이유 |
|------|-----------|------|
| 화자별 음단절 위치 특정 | 대본 기반 | 대사 인덱스와 화자 정보 보유 |
| 깨짐·왜곡 검출 | 오디오 기반 | gain_drop 타입 전용 알고리즘 |
| 오탐 최소화 (False Positive 방어) | 대본 기반 | 발화 구간 한정 검사 |
| 미탐 최소화 (False Negative 방어) | 오디오 기반 | 전 구간 frame 단위 전수 검사 |
| 보고서용 수치 (gain_db, 정밀 타임스탬프) | 오디오 기반 | 구조화된 수치 데이터 반환 |

### 5.3 현재 구현: `analyze_hybrid.py`

```python
# 두 방법을 병렬로 실행하여 하나의 리포트에 통합
_anomaly_events  = detect_dif_only_events(ref_path, dif_path)   # 오디오 기반
_dropout_and_raw = analyze_by_script(ref, test, script, speaker) # 대본 기반
```

- 오디오 기반 결과 → HTML 이상 구간 테이블 (타입·시간·gain_db)  
- 대본 기반 결과 → 화자별 음단절 여부 + 상관계수 + MOS 지표

## 6. 기술적 우위 정리

### 대본 기반의 핵심 차별점

대본 기반 접근은 단순한 신호 처리가 아니라 **통화 내용의 의미적 구조를 검출에 활용**한다는 점이 근본적 차별점입니다.

> "이 구간에 어떤 음성이 있어야 하는지 알고 있다" → 없으면 음단절

이는 일반적인 오디오 이상 검출 도구가 제공할 수 없는 **품질 보증(QA) 자동화** 관점의 접근입니다.  
테스트 케이스·대본·자동화 파이프라인이 준비된 환경에서는 오디오 기반보다 훨씬 낮은 오탐률을 달성합니다.

### 오디오 기반의 핵심 차별점

대본 없이도 작동하며, **깨짐(gain_drop)이라는 차원이 다른 이상 유형**을 커버합니다.  
DTW 정렬 덕분에 복잡한 탈락 패턴에서도 정렬이 유지됩니다.

### 두 기법이 공존해야 하는 이유

단독으로는 서로의 맹점을 채울 수 없습니다.  
대본 기반이 False Positive를 막는 동안 오디오 기반이 False Negative와 깨짐을 막습니다.  
결과적으로 **전체 검출 정확도는 두 방법의 교집합·합집합 신뢰도 계층화**를 통해 단독 방법보다 유의미하게 향상됩니다.

## 7. 향후 개선 방향

| 방향 | 설명 |
|------|------|
| 교차 검증 자동화 | 두 방법의 결과를 `analyze_hybrid.py`에서 자동 비교하여 confidence score 산출 |
| 대본 기반 + gain_drop 결합 | 화자 발화 구간 내 깨짐 검출을 위해 오디오 기반 gain_drop 결과를 대본 구간과 교차 |
| 반복 학습 | 오탐·미탐 케이스를 누적하여 `CORR_GOOD`, `CORR_THRESHOLD` 등 임계값 통계적 조정 |
| 실시간 적용 | 스트리밍 환경에서 대본 기반 방식(낮은 계산 비용)을 실시간 경보로 먼저 사용 |
