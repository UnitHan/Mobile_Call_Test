**`src-tauri/src/lib.rs`** — 4개 커맨드 import 및 `invoke_handler` 등록

## 4. #3001 / #3004 — Line In 음원 주입 미작동 버그 수정

### 증상
오디오 인터페이스 지정(LocationID 고정)은 정상 작동하나, Line In으로 휴대폰에 음원 재생·주입이 안 됨.  
#3004 테스트로 최종 정상 확인.

### 원인 분석

#### 버그 1 — `_usb_order_for_device` (audio_playback_mixin.py)
```python
# Before (버그): 'USB' 문자열이 이름에 없는 장치(CONNECT 6 등) 미감지
usb_outputs = sorted([
    i for i, d in enumerate(sd.query_devices())
    if d['max_output_channels'] > 0 and 'USB' in d['name']  # ← CONNECT 6 미감지
])
```
CONNECT 6의 sounddevice 장치명에 'USB'가 포함되지 않아 `usb_order`가 항상 `None` 반환.  
`usb_order=None`이면 macOS 재열거 시 복구 로직이 동작하지 않고, `output_pair` 채널 매핑도 잘못된 장치로 전달됨.

#### 버그 2 — `_recover_usb_device` (audio_player_worker.py)
```python
# Before (버그): 동일 원인
is_usb = 'USB' in dev_name  # ← CONNECT 6 미감지 → 복구 로직 진입 불가
```

#### 버그 3 — `play()` 복구 경로 (audio_player_worker.py)
```python
# Before (버그): 'USB' 이름 필터로 직접 목록 생성
all_usb = sorted([
    i for i, d in enumerate(sd.query_devices())
    if d['max_output_channels'] > 0 and 'USB' in d['name']  # ← CONNECT 6 누락
])
```

#### 버그 4 — `save_audio_interface_config` (usb_audio_devices.py)
```python
# Before (버그): config.py의 device_index를 입력 인덱스(sd_in)로 저장
new_text = _replace_device_block(text, 'android_a', android_location_id, android_in)  # ← sd_in 잘못 사용
```
`config.py`의 `device_index`는 **출력(output)** 폴백 인덱스인데 입력 인덱스를 저장.  
오디오 인터페이스 탭에서 저장 후 `device_index_fallback`이 입력 인덱스로 덮여, locationID 폴백 시 잘못된 장치로 재생.

#### 버그 5 — `runOnce()` 파라미터 누락 (App.tsx)
단일 테스트 실행(`handleStartTest`) 시 `speaker1RecChannel` / `speaker2RecChannel`이 `run_ixio_test` 호출에 포함되지 않아 RecChannel 설정이 무시됨.  
(TC 모드 `useTcRunner.ts`에는 이미 포함되어 있었음)
