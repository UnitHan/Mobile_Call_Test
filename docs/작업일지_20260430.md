## 1. WDA 단말 선택 드롭다운 → 설정 모달 이동

### 배경

`DeviceSection` 내 WDA row에 iOS 기기 선택 `<select>` 드롭다운이 추가되면서 공지사항 전광판 영역이 지나치게 좁아지는 UI 문제 발생. iOS 기기가 2대 이상 연결된 경우에만 표시되던 드롭다운을, 상시 표시되는 설정 모달의 **단말/전화번호 탭**으로 옮겨 공지사항 공간을 복원.

### 변경 내용

#### `src/App.tsx`
- `wdaUdid` state 추가 (localStorage 영속화)
  ```tsx
  const [wdaUdid, setWdaUdid] = useState<string>(
    () => localStorage.getItem("wdaUdid") ?? ""
  );
  const handleWdaUdidChange = (v: string) => {
    setWdaUdid(v);
    localStorage.setItem("wdaUdid", v);
  };
  ```
- `<DeviceSection>` 에 `wdaUdid={wdaUdid}` prop 전달
- `<SettingsModal>` 에 `iosDevices`, `wdaUdid`, `onWdaUdidChange` prop 전달

#### `src/components/DeviceSection.tsx`
- 내부 `useState<string>("")` 제거 → `wdaUdid?: string` prop으로 교체
- WDA row에서 `<select>` 드롭다운 완전 제거
- 선택된 기기가 있을 경우 기기명만 작게(0.75rem) 표시
- `targetUdid = wdaUdidProp || iosDevices[0]?.udid` 로직 유지

#### `src/components/SettingsModal.tsx`
- `interface Props`에 `iosDevices?: DeviceInfo[]`, `wdaUdid?`, `onWdaUdidChange?` 추가
- `DeviceInfo` 타입 import 추가
- **단말/전화번호 탭** 최하단에 WDA 섹션 추가
  - `iosDevices.length > 1` 일 때만 표시
  - 📱 WDA 섹션 타이틀 + 대상 기기 select

#### `src/i18n/locales/ko.ts` / `en.ts`
| 키 | 한국어 | 영어 |
|---|---|---|
| `settings.deviceTab.wdaDevice` | WDA 대상 기기 | WDA Target Device |
| `settings.deviceTab.wdaDeviceHint` | WDA를 설치·실행할 iPhone | iPhone to install / run WDA on |

## 2. Appium 세션 만료 자동 재연결 (`tc_base.py`)

### 배경

반복 테스트 도중 iOS Appium 세션이 만료(`Session does not exist`)되면 이후 모든 회차가 연쇄 실패하는 문제. 오류를 감지하면 세션을 재생성하도록 수정.

### 변경 내용

#### `src-tauri/scripts/tc_base.py`
- `_relaunch_ixio_speaker2()`, `_relaunch_ixio_speaker1()` 내부에 세션 만료 감지 로직 추가
  ```python
  if 'Session does not exist' in _emsg or 'invalid session id' in _emsg.lower():
      ok = self.setup_device(self.speaker2_device, 'speaker2', platform='iOS')
      # 재연결 후 앱 재실행
  ```
- `target/debug/scripts/` 동기화 완료
