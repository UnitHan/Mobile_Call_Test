## 3. WDA 기동 방식 전환 — `devicectl` → `xcodebuild test-without-building`

### 문제
`devicectl device process launch`로는 XCTest 런너 HTTP 서버가 기동되지 않음.  
`USE_PORT` 등 XCTest 환경 변수를 전달하지 못하기 때문.

### 원인 분석
xctestrun 파일 내 `USE_PORT=8110` 설정 확인:
```python
# xctestrun plist 파싱 결과
Target: WebDriverAgentRunner
  USE_PORT: 8110
  MJPEG_SERVER_PORT: 9110
```
WDA가 기본 8100이 아닌 **8110**에서 리슨하고 있었음.

### 해결 (`ios_wda_manager.py` — `launch_wda_via_devicectl`)

`devicectl process launch` → `xcodebuild test-without-building` 방식으로 교체:
- DerivedData에서 최신 `.xctestrun` 파일 자동 탐색
- xctestrun의 `USE_PORT` 값을 plistlib으로 읽어 포트 동적 결정
- `subprocess.Popen`으로 백그라운드 실행 후 최대 60초 대기

```python
subprocess.Popen([
    'xcodebuild', 'test-without-building',
    '-xctestrun', xctestrun,
    '-destination', f'id={udid}'
], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
```
