## 4. 한국어/영어 이중언어(i18n) 지원 전면 적용

### 4-1. 배경 및 목표

설정 메뉴에 언어 설정 UI를 추가하고, 앱 전체를 한국어/영어로 전환할 수 있도록 i18n 시스템을 구축.

### 4-2. i18n 아키텍처

| 파일 | 역할 |
|------|------|
| `src/i18n/locales/ko.ts` | 한국어 번역 딕셔너리 (진리의 원천, `as const`) |
| `src/i18n/locales/en.ts` | 영어 번역 딕셔너리 (`Translations` 타입 적용) |
| `src/i18n/index.tsx` | `LanguageProvider`, `useT()` 훅, `t()` 함수 |

**주요 설계 결정:**
- 언어 상태: `localStorage("ixio-lang")`, 기본값 `"ko"`
- 번역 접근: 점(`.`) 구분 경로 (`t("header.statusRunning")`)
- 변수 보간: `{var}` 문법 (`t("status.tcRunning", { tcId: "TC_01" })`)
- 타입 안전성: `DeepString<typeof ko>` 재귀 매핑 타입으로 `as const` 리터럴과 `string` 타입 충돌 해결

```typescript
// ko.ts 하단
type DeepString<T> = { [K in keyof T]: T[K] extends Record<string, unknown> ? DeepString<T[K]> : string };
export type Translations = DeepString<typeof ko>;
```
