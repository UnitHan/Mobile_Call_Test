# ixi-O 통화기능 자동화 테스트 솔루션

> **AI 보이스피싱 탐지 · 통화 품질 분석 · 음단절 검출 — 올인원 자동화 테스트 플랫폼**

---

## 프로그램 개요

**ixi-O 통화기능 테스트**는 LG U+ ixi-O AI 통화 에이전트의 통화 품질과 보안 기능을 **무인 자동화**로 검증하는 End-to-End 테스트 솔루션이다.

실제 단말(iPhone + Android)에서 통화를 자동 수행하고, 녹음된 음원을 **국제 표준 음질 지표(ViSQOL MOS)**로 분석하며, **음단절(Dropout)** 구간을 대사 단위로 정밀 검출하고, **AI 생성 보이스피싱 음성 차단 여부**까지 한 번에 검증한다.

---

## 핵심 기능

### 1. 통화 품질 자동 측정 (MOS 분석)

| 항목 | 내용 |
|------|------|
| **측정 지표** | ViSQOL MOS (ITU-T P.863 기반, 0~5점) |
| **보조 지표** | PESQ, SNR (Signal-to-Noise Ratio) |
| **측정 방식** | 정답지 음원(Reference)과 녹음 음원(Degraded) 비교 분석 |
| **양방향 측정** | iOS→Android, Android→iOS 각각 독립 측정 |
| **등급 판정** | Excellent(≥4.5) · Good(≥4.0) · Fair(≥3.5) · Poor(≥3.0) · Bad(<3.0) |

```
정답지 음원 (깨끗한 원본)
        ↕  ViSQOL 비교 분석
녹음 음원 (실제 통화 수신)
        ↓
    MOS 점수 산출 (예: 3.732)
```

**포인트**: 사람의 귀로 듣고 주관적으로 판단하는 기존 방식 대비, **국제 표준 알고리즘으로 객관적·정량적** 품질 수치를 자동 산출한다.

---

### 2. 음단절(Dropout) 정밀 검출

| 항목 | 내용 |
|------|------|
| **검출 방식** | VAD(Voice Activity Detection) + 교차 상관(Cross-Correlation) 분석 |
| **분석 단위** | 대사(Script line) 단위 — 어떤 문장에서 끊겼는지 특정 |
| **임계값** | 상관계수 0.30 미만 → 음단절 판정 |
| **심각도 분류** | 없음 · 경미 · 보통 · 심각 (4단계) |
| **출력 정보** | 구간 시각(초), 길이(ms), 대사 텍스트, 상관계수, 판정 결과 |

```
대사 #3 「주민등록번호 확인 부탁드립니다」
  정답지 구간: 8.2–10.5s (2300ms)
  상관계수: +0.012  ← 정상 기준(0.30) 미달
  판정: ⛔ 음단절
```

**포인트**: 단순 "끊김 있음/없음"이 아니라, **몇 번째 대사의 몇 초 구간에서 어떤 수준으로 끊겼는지** 정확히 리포팅한다.

### 3. AI 보이스피싱(Vishing) 탐지 검증

| 항목 | 내용 |
|------|------|
| **테스트 시나리오** | 실제 보이스피싱 대본(검찰 사칭) 음원으로 통화 시도 |
| **검증 대상** | ixi-O의 AI 위조 음성 탐지 팝업 정상 동작 여부 |
| **검출 방법** | 통화 중 단말 스크린샷 자동 캡처 → 경고 팝업 표시 확인 |
| **판정 결과** | ✅ PASS (팝업 감지됨) / ❌ FAIL (팝업 미감지) |

```
보이스피싱 대본 재생 (가해자 역할 음원)
        ↓
  ixi-O AI 엔진이 위조 음성 감지
        ↓
  단말 화면에 경고 팝업 표시
        ↓
  자동 스크린샷 캡처 → 팝업 존재 확인
        ↓
  PASS ✅ — 탐지 성공
```

**포인트**: 보이스피싱 차단 기능이 실제 통화 환경에서 **정상 작동하는지 자동으로 검증**한다. 수동 테스트 대비 일관된 시나리오 재현이 가능하다.

---

### 4. 양방향 통화 테스트

| TC | 방향 | 발신 | 수신 | 검증 항목 |
|----|------|------|------|-----------|
| **TC_01** | 정방향 | S1 (iPhone) | S2 (Android) | 통화 품질 + 음단절 |
| **TC_02** | 역방향 | S2 (Android) | S1 (iPhone) | 통화 품질 + 음단절 |
| **TC_03** | 정방향 보이스피싱 | S1 (iPhone) | S2 (Android) | 품질 + 음단절 + AI 탐지 |
| **TC_04** | 역방향 보이스피싱 | S2 (Android) | S1 (iPhone) | 품질 + 음단절 + AI 탐지 |

**포인트**: 발신↔수신 방향에 따라 품질 차이가 발생할 수 있으므로, **양방향 테스트로 비대칭 문제까지 검출**한다.

### 5. 완전 무인 자동화 실행

| 항목 | 내용 |
|------|------|
| **디바이스 제어** | Appium 2.x 기반 — iOS(XCUITest) + Android(UIAutomator2) |
| **자동 실행 흐름** | 전화 앱 실행 → 번호 입력 → 발신 → 음원 재생 → 녹음 수집 → 분석 → 리포트 |
| **반복 실행** | N회 반복, Set 단위 또는 TC 단위 선택 가능 |
| **실패 정책** | 실패 시 중단 / 계속 진행 / 크래시 시 재시도 — 3가지 선택 |
| **예약 실행** | N분 후 자동 시작 (카운트다운 타이머) |
| **1회 소요 시간** | TC 1건당 약 50~70초 |

```
[시작] → 환경 점검 → 디바이스 연결
  → TC_01 실행 (정방향)
  → TC_02 실행 (역방향, 자동 스왑)
  → TC_03 실행 (보이스피싱 정방향)
  → TC_04 실행 (보이스피싱 역방향)
  → 반복 (설정 횟수만큼)
[완료] → 전체 결과 대시보드 표시
```

**포인트**: 테스터가 **버튼 한 번 누르면** 전체 테스트 시나리오가 자동 수행된다. 야간/주말 무인 테스트 운영이 가능하다.

### 6. 실시간 대시보드 & 모니터링

| 기능 | 설명 |
|------|------|
| **실시간 상태** | RUNNING · QUEUED · PASS · FAIL · ERROR 실시간 표시 |
| **로그 스트림** | 테스트 실행 로그 실시간 콘솔 출력 |
| **결과 이력** | 전체 실행 이력 조회, 세션별 그룹핑 |
| **결과 상세** | 개별 결과 클릭 → MOS 점수, 음단절 현황, 녹음 파일, 스크린샷 확인 |
| **데이터 내보내기** | CSV/Excel 원클릭 다운로드 |
| **보고서 생성** | HTML 분석 보고서 자동 생성 (차트 + 테이블 포함) |

**포인트**: 테스트 진행 상황을 **실시간으로 모니터링**하고, 결과를 즉시 확인·공유할 수 있다.

### 7. 상세 HTML 분석 보고서

보고서 1건에 포함되는 내용:

| 섹션 | 내용 |
|------|------|
| **테스트 메타데이터** | 실행 시각, 소요 시간, 디바이스 정보, TC 유형 |
| **MOS 점수 요약** | iOS/Android 각각 MOS 점수 + 등급 뱃지 |
| **음단절 분석표** | 대사별 판정 결과 테이블 (구간, 길이, 상관계수, 판정) |
| **파형 비교 차트** | 정답지 vs 녹음 음원 시각적 비교 그래프 |
| **보이스피싱 결과** | AI 탐지 판정 + 스크린샷 갤러리 |
| **종합 판정** | PASS/FAIL + 심각도 뱃지 |

**포인트**: 분석 결과를 **시각적으로 정리된 보고서**로 자동 생성하여, 별도 문서 작성 없이 즉시 공유·보고할 수 있다.
